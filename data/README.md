# Dataset provenance

**Dataset:** Early Stage Diabetes Risk Prediction (UCI ML Repository, ID 529)

**Source:** https://archive.ics.uci.edu/dataset/529/early+stage+diabetes+risk+prediction+dataset

**DOI:** https://doi.org/10.24432/C5VG8H

**License:** CC BY 4.0 (attribution required).

The source data are questionnaire-based symptoms collected from Sylhet Diabetes
Hospital (Bangladesh); it is not a longitudinal study of future diabetes.
This repository does not include the source CSV by default. Use the provided
script to retrieve it, or download it from UCI and place it under `data/raw/`.
The code uses this source with attribution, and the MIT code license does not
supersede the dataset's CC BY 4.0 license.
